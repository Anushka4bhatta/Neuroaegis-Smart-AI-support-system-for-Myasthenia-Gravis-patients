# Neuroaegis-Smart-AI-support-system-for-Myasthenia-Gravis-patients
NeuroAegis is an AI-powered healthcare system for Myasthenia Gravis patients featuring machine learning-based fatigue detection, voice fatigue analysis, ptosis detection using computer vision, health logging, chatbot assistance, and an interactive web dashboard built with Python, Flask, HTML, CSS, and JavaScript.
